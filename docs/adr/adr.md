## Elegir y justificar en ADR 0002

### Stack moderno basado en React + Firebase + Google AI Studio

PHP + XAMPP

Pros: fácil de instalar, muy usado en proyectos pequeños.

Contras: arquitectura monolítica, poca escalabilidad, seguridad limitada, difícil integración con IA moderna.

Comparación: Firebase ofrece escalabilidad en la nube y seguridad integrada, mientras que PHP/XAMPP requiere mucha configuración manual.

Bases de datos SQL locales (MySQL en servidor propio)

Pros: conocidas, robustas.

Contras: requieren administración de servidores, backups, escalado manual.

Comparación: Firestore escala automáticamente y guarda datos en tiempo real, ideal para triage clínico.

Frameworks antiguos de frontend (ej. jQuery + HTML plano)

Pros: simples, rápidos de aprender.

Contras: difícil mantener aplicaciones grandes, poca modularidad.

Comparación: React permite componentes reutilizables y mejor experiencia de usuario.

Motores de IA caseros (Python local sin API)

Pros: control total.

Contras: difícil cumplir con leyes de datos de salud, no garantiza disponibilidad ni soporte.

Comparación: Google AI Studio ofrece API segura, escalable y con trazabilidad.
