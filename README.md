# EQUIPO MediTriage 
### *Integrantes*: Jhorgely, Gibran, Benjamin, Vicente, Deyner
### *Iniciativa elegida*: MediTriage — Triage clínico asistido por IA
### *Objetivo*: El objetivo es crear una plataforma que priorice pacientes en la sala de espera usando IA sobre síntomas reportados, historia clínica y signos vitales, respetando la normativa chilena de datos sensibles (Ley 19.628 y Ley 21.719).
